# Presentation DESIGN.md contract

Create a compact design system before authoring slides. The purpose is consistency, not documentation volume.

## Recommended sections

1. **Intent** — audience, tone, emotional goal, what the deck must not feel like.
2. **Canvas & grid** — aspect ratio, margins, content safe area, base columns.
3. **Palette** — background, text, muted text, accent(s), semantic colors.
4. **Typography** — title/body/data/label hierarchy, preferred fonts and fallbacks.
5. **Spacing & geometry** — spacing rhythm, border radius, stroke, shadow policy.
6. **Imagery** — photo crop, illustration style, icon language, screenshot treatment.
7. **Data visualization** — chart hierarchy, labels, gridlines, annotation style.
8. **Motion / presentation behavior** — restrained; avoid effects that cannot survive PPTX export.
9. **Anti-patterns** — visual choices explicitly forbidden for this deck.

## High-visual defaults

- Prefer one confident visual gesture over many decorations.
- Use strong editorial hierarchy.
- Keep a limited palette; accent color is scarce.
- Use whitespace intentionally.
- Treat screenshots and photographs as designed objects.
- Avoid endless card grids.

## Brand mode

Brand Pack rules override generic defaults. Locked logo/background/header/footer locations must not drift. The content canvas can still use varied editorial layouts unless strict-template behavior was explicitly requested.

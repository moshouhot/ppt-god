# Editability levels

## E1 — Native-first

Use when users expect to update charts, tables, and diagram elements repeatedly in PowerPoint. Prioritize native text, charts/tables, and shapes. Accept lower visual complexity when necessary.

## E2 — Hybrid (default)

Use for most professional decks. Require editable titles/body text and key numbers where practical. Allow SVG/raster backgrounds and complex visual treatments. This usually gives the best quality/cost trade-off.

## E3 — Visual-first

Use for launch keynotes, stage decks, one-off pitches, and cases where appearance matters more than future editing. Allow entire slides or large visual regions to rasterize when that is the most faithful export.

## Decision rule

- "I need to edit everything later" → E1
- no explicit preference → E2
- "make it look amazing; I mainly present it" → E3
